# Getting Started

This guide helps you onboard quickly.

## Prerequisites

- Access to the repository
- GitBook space connected via Git Sync (root: `/docs`)

## Local steps

1. Create or edit pages under `docs/`
2. Update `docs/SUMMARY.md` to add to the sidebar
3. Open a PR with `docs:` commit messages

## Publishing

- Merges to `staging` → GitBook preview
- Merges to `main` → GitBook production
