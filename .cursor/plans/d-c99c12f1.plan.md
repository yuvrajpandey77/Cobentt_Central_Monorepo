# Dapp Studio: Deploy Wizard & Codegen Implementation Plan

## Scope

- EVM (Solidity) MVP with 3 templates: ERC20, ERC721, PaymentSplitter
- Solana (Rust/Anchor) v0.1 with SPL Mint and Escrow
- Stepper-based Deploy Wizard: Artifacts → Wallet → Fund → Preflight → Deploy → Verify → Bind Dapp

## Architecture

- Keep Next.js app dir; backend via route handlers under `src/app/api/**`
- Background processing via Inngest (`src/inngest/**`) and sandbox builds
- Templates + codegen engine in `src/lib/codegen/**`
- Artifacts storage (S3 or local dev) with URLs persisted in DB

## Data Model (Prisma)

- Update `prisma/schema.prisma` with `Project`, `BuildJob`, enums (Chain, Language, JobType, JobStatus)
- Regenerate Prisma Client

## Templates & Codegen

- Directory: `templates/evm/<templateKey>/**`, `templates/solana/<templateKey>/**`
- Dapp templates: `templates-dapp/evm/**`, `templates-dapp/solana/**`
- Codegen executor in `src/lib/codegen/generate.ts`: render files from template + config; outputs artifacts
- Compiler adapters:
- EVM: Foundry/solc wrapper `src/lib/codegen/evm/compile.ts`
- Solana: Anchor `src/lib/codegen/solana/build.ts` (backend-only)

## API Routes

- `POST src/app/api/projects/route.ts` → create project from template config
- `POST src/app/api/projects/[id]/generate/route.ts` → enqueue GENERATE → COMPILE → PACKAGE
- `GET src/app/api/projects/[id]/artifacts/route.ts` → return `{ abi, bytecode, idl }`
- `POST src/app/api/deploy/evm/route.ts` → persist tx receipt and address (client deploys)
- `POST src/app/api/faucet/evm/route.ts` → relayer drip from testnet hot wallet (rate-limited)
- `POST src/app/api/verify/evm/route.ts` → Sourcify/Etherscan verify
- `POST src/app/api/deploy/solana/route.ts` → enqueue Anchor deploy (returns `programId`)

## Inngest Jobs

- File: `src/inngest/functions.ts`
- `project.generate` → render template → compile → package → upload ZIP
- `project.deploy.solana` → anchor build/deploy in sandbox → return `programId` + IDL
- `project.verify.evm` → push sources/metadata to Sourcify

## Frontend (Wizard UI)

- Route: `src/app/projects/[projectId]/deploy/page.tsx`
- Components under `src/modules/projects/ui/deploy-wizard/**`
- Steps: `ArtifactsStep`, `WalletStep`, `FundStep`, `PreflightStep`, `DeployStep`, `VerifyStep`, `BindDappStep`
- Hooks: `src/hooks/projects/**` (TanStack Query): `useProject`, `useArtifacts`, `useFaucet`, `useVerifyEvm`, `useBindDapp`
- Wallet (EVM): Wagmi/Viem + RainbowKit config under `src/lib/wagmi.ts`
- For Solana (v0.1): Wallet Adapter in separate step when enabled

## Dapp Scaffold Binding

- On success, write `CONTRACT_ADDRESS` (EVM) or `PROGRAM_ID` (Solana) into scaffold
- Repackage ZIP and expose `dappZipUrl` via artifacts API

## Security & Compliance

- Never store user private keys; EVM deploy is client-signed
- Faucet relayer is testnet-only; strict rate limits, audit logs
- Store compiler settings for verification
- Secrets via environment variables with per-env separation

## Observability

- Job logs persisted to `BuildJob.logs`
- UI progress via polling `GET /api/jobs/:id` or SSE (future)
- Explorer links after deploy/verify

## Rollout

- v0 (EVM ERC20/721/PaymentSplitter + faucet + deploy + Sourcify + dapp ZIP)
- v0.1 (Solana SPL + Escrow; devnet airdrop; Anchor deploy; IDL publish)
- v0.2 (Upgradeable + Governor/Timelock, Subgraph starter, Learning mode)
